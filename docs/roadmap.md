# Roadmap

## MVP 0.1

- Fresh Apps Script scaffold.
- Canonical Sheets schema.
- Bootstrap helper.
- Auth, roles, permissions.
- Assignment Board.
- Task/general time entry.
- Owner/Admin all-user time review.
- Pay-period totals.
- Open/Locked pay periods.
- Audit log.

## MVP 0.2

- Saved Assignment Board filters and grouping.
- Tags table and searchable task tag dropdowns.
- Locked-period time edit request workflow.
- Settings side-pane and profile editing.
- Manager permission presets and overrides.
- Pay-period lock/unlock.
- More complete mobile QA pass.

## MVP 0.3

- Google Chat webhook notifications for task created/completed.
- Thread key support.
- Notification feature flags.

## Later

- Optional personal Google Tasks mirroring.
- Gmail weekly summaries and missing-time reminders.
- Calendar-based time entry suggestions.
- Performance tuning for larger sheets.
- Optional frontend framework only if the vanilla app becomes a maintenance bottleneck.
